Il progetto si compone di un lato client e un lato server (php). 
il tema è libero e "non deve essere non equilibrato" (tipo troppo client e poco server e viceversa)
Esempi: 
- Applicazione gestionale ( senza lato client effimero però)
- Sviluppo videogame ( più complessità lato client in javascript , ma il lato server deve essere comunque ben curato (classifiche, salvataggio di partite in stati intermedi ...))
